What was corrected from the original

  • MCP is not a mandatory "standard layer." The original drew it as the foundation under Skill. In reality it's an optional transport for external tools — most tools call directly via function-calling and never touch MCP.
  • Skill ≠ Tool. The original labeled "search / calculate / API call" as Skills — those are Tools (single calls). A Skill is a packaged method that may invoke several Tools.
  • It isn't a clean bottom-up stack. Real shape: the Agent (loop) drives the LLM (brain), acts through Tools/Skills, some of which arrive via MCP, with the Harness cutting across and wrapping all of it.
In one line: LLM = brain · Agent = the loop that executes · Tool/Skill = hands and feet (Skill is a packaged method) · MCP = optional transport · Harness = engineering assurance
