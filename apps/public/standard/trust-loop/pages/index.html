Trust Loop

How an engineering calculator earns trust — live. This page computes IEEE Std 80 tolerable touch and step voltages from a pure, deterministic engine, shows its working line by line, and runs the standard's own published case as a conformance gate. The interface computes nothing; every number comes from the engine.

Inputs

The published case — ρ=100 Ω·m, t=0.5 s, 50 kg, no surface layer — resolves to 188.65 V touch and 262.48 V step in the standard itself. That pair of numbers is this calculator's conformance anchor below.

The gate re-runs the engine against the standard's published numbers on demand. If the computed values drift outside ±0.5%, the case fails — there is no argument to have with a gate.

Where the AI sits: a model may draft an engine like this one, but the draft carries no authority — it is a candidate until the gate passes it. At runtime no model is on the compute path: the value is produced by the same pure function every time, and the formula note cited on the inputs is the clause the code implements.
