# 03 雙掛點軟布：從塑膠感到動畫啞光

這是《Spark》的已渲染案例，補充 `animation-examples.md` 的機制教學。
沿用五秒、24 fps 的同一段布料動作比較材質。它是候選鏡頭，沒有最終
藝術批准；使用者指出過塑膠感，後來觀察新版有啞光感，不能把這句話
記成全片或鏡頭已批准。

## 打開樣例

由 repository 根目錄定位：

- 工程：`data/blender-animation-examples/03-soft-cloth/03-soft-cloth.blend`
- 原曲樂句預覽：同目錄 `spark-phrase-review.mp4`
- 材質對照：同目錄 `before-after.jpg`
- 來源、hash 與限制：同目錄 `manifest.json`、`source-clip-qa.json`

工程包含打包背景及 120 幀烘焙 Shape Keys，不需要下載模型或外部模擬
快取。這是打包案例，**不是**前兩個樣例那種無素材生成器。音樂僅在
本地樂句預覽內，未嵌入工程；不要將歌曲或背景當作可任意再分發的
技能素材。材質使用 EEVEE 的 Shader to RGB，不能直接切到 Cycles。

## 掛點與柔軟度

後續使用者修正：垂墜性好的布料不應預製密集規律褶皺。褶皺應主要
由懸掛、重力與風產生。早期案例的 45mm 規律初始起伏因此不應照搬。
後續 D 對照改為平順初始面，只留 3mm 的寬幅不對稱擾動與掛點間餘量；
它是初始化偏差，不能稱為布料固有紋理。原打包案例保留作歷史對照。
加密近處網格至 84×120、保持頂點質量總和的 B 對照增加細碎褶皺卻
減弱掀起，未被接受為修復；改網格還會改變離散剛度／碰撞行為。
不能把「更多格數」等同「更自然」。

兩個上角保持固定，其間需有布長餘量，才能自然下墜。只把一條繃直
的上緣兩端 pin 住，再降低 bending，不能保證得到所需的垂墜輪廓。
本例先給上緣鬆弛弧線與細小深度起伏，再讓重力和自碰撞求解。

近、中、遠網格分別 42×60、28×40、22×32；本例 cloth quality 12、
mass 0.025、bending 0.015、shear 8。這些是此尺寸與網格的記錄，
不是棉布的通用物性；網格、尺寸或質量改變後要重新平衡風力。

先算 96 幀預滾，再保留 120 個連續模擬姿態。三張布的風延遲為
0／7／14 幀，seed 730／737／744；風峰值 1508 是 Blender 此案例的
控制值，不是實際風速。先看布邊輪廓、起勢和回落，再看細褶。
靠近攝影機的深度擺動可能很大，但正面輪廓仍近乎不動。

## 外觀：不要只看節點有沒有 specular

前版沒有明確 glossy 節點，卻因強烈暖色條帶和細小法線起伏，被
使用者讀成塑膠布。可見結果優先於 shader 名稱。修正順序：

1. 保留已測的動作，先降低暖光強度、增大光源，移除細密 bump。
2. 限制布面的明暗範圍，以米白／藍灰的大色面表達陰影。
3. 硬切 cel 色階曾把細褶切成碎斑；改成低對比、柔和過渡的色階。
4. 細格紋與弱纖維噪聲使用 UV，隨布面變形；不要固定在畫面上。
5. 暖色背光只作受限染色。此版最大混合量 6%，是動畫化近似，
   不是已驗證的物理透光率。啞光也不能把布面壓平到像厚紙。

節點思路：Diffuse → Shader to RGB → 限幅色階 → UV 紋理 → 柔和暖色
混合 → Emission 輸出。Translucent → Shader to RGB 只提供受限的
背光染色權重。這裡的 emission 是呈現色階的方式，不代表布在發光。
暖光透過薄布、看穿背景、鏡面反射是三種不同現象，分開判斷。

## 驗證與限制

- 原案例 119 對相鄰影格沒有完全重複；抽查的固定地面區域差值為零。
- 原始模擬 pin 誤差最大約 2.4e-7 場景單位。這只檢查求解頂點，
  不證明夾具表面接觸、繩索碰撞或所有渲染輪廓都正確。
- `PRESERVE_CORNERS` 用於細分邊界；重開後仍需檢查可見掛點。
- 暖燈開關、透光開關要做對照；像素有差異只能證明設定影響畫面，
  不能單獨證明真實光學模型成立。
- 背景為固定插畫，門口光源位置是單視角近似，原圖地面光影沒有
  隨模擬重新計算。禁止把它稱作完整原生 3D 場景。
- 抽幀視看和逐幀數值檢查不等於正常播放審美。音樂適配仍須在
  真正樂句內觀看；沒有直接聽審能力時明確記錄。

可練習：同一動作比較硬切／柔化色階；只改光源大小觀察亮帶；
只改上緣餘量觀察 pin 間垂墜。每次改一個問題，不為增加技術混合
而重建已成立的動作。
