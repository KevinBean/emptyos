01 — GENERATION

Not just a render

Most "AI CAD" stops at a pretty picture. SolidBench compiles every generated part into exact boundary-representation geometry, then checks it before it ever reaches you.

GEOMETRY GATE

Nothing broken ships

Every part is checked for non‑manifold surfaces, zero‑volume bodies, and out‑of‑scale geometry before you ever see it. A failed part is regenerated, not handed to you to debug.

VISUAL CHECK

A second opinion, on demand

One click sends the rendered part to a vision model, graded against what you actually asked for — catching the gap between "compiles fine" and "is what I meant" before you export.

REAL PARAMETERS

Tweak it after

Every generated part keeps its feature tree — box, hole, fillet, boolean — so you can adjust a dimension directly instead of re‑prompting from scratch.

02 — Versioning

Git, for solids.

Branch a design before you try something risky. Fork a variant for a client. Merge two people's edits back together — and when you both touched the same feature, SolidBench tells you exactly where the conflict is instead of silently picking a winner.

  • Every save is a recorded, restorable revision
  • Branch, fork, and checkout like a real history
  • Structural merge at the feature level — not a text diff

03 — Collaboration

Work on it together.

Send one link. Whoever opens it is editing the same live model you are — same viewport, same feature tree, converging in real time. No exporting a file back and forth, no "final_v3" in the filename.

  • Live cursors and presence for every collaborator
  • Edits converge automatically, in either direction
  • One shareable link grants write access — nothing to install
04 — OUTPUT

From model to the shop

A model that only lives in the browser isn't finished. SolidBench produces the two documents an actual shop or supplier asks for.

STEP EXPORT

Exact geometry, not a mesh

The same boundary‑representation solid you designed with — not an approximated triangle mesh — ready for any CAD system or CAM package downstream.

2D DRAWINGS

Dimensioned, automatically

Orthographic views generated straight from the solid, with dimensions placed on the real edges — a drawing you could actually hand to a machinist.
