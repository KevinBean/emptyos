Persistent memory

Claude Code is brilliant inside a single session. Between sessions, it forgets your decisions, your patterns, your project history. Plekto remembers — across days, projects, and machines.

▥

Project workspaces

Switch between projects without losing context. Each one carries its own knowledge base, task list, file tree, and conversation history. Pick up a project from last month exactly where you left it.

⌥

Multi-agent rooms

Run multiple agents in one room — Claude Code, Codex, Gemini — and review every action before it executes. The pending-action gate means agents propose; you decide.

Plekto is one curated distribution of EmptyOS — a local-first AI operating system you own, not an agent you rent. Consent-gated, AGPL-3.0, your data in plain markdown that outlives the app. The source is open and yours to fork.
